01

三条结论

先给判断，再给证据。下面每个 P0 都附了实测截图与重绘的修复示意。

保留
设计令牌 + 状态色分离

主色只用于可点击动作、6 种状态各自成套、情感三色与状态色不共用——这套约束是对的，不要动。它解决了「看起来是蓝色=能点」的误读，是这份设计最值钱的部分。

修复
表格的「横向预算」失控

审核队列 8 列 + 固定操作列，在 1440 下已溢出：预审列被压掉一半、5 个文字按钮折成两行。表格是全系统使用频率最高的组件，必须建立列宽预算与「主操作 + 更多」的收敛规则。

收敛
字号与灰度层级过碎

字号用了 10 档（11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 16 / 17 / 20），灰度用了 4 级且最浅两级对比度仅 3.0:1 与 2.0:1。收敛到 6 档字号 + 3 级灰度，顺手把可访问性补齐。

02

P0 · 阻断项（答辩前必改）

这四项不是「不够好看」，而是「看起来像坏了」：内容被裁切、标签互相压字、同一屏出现三个空态。

P0-3

待发布页：同一屏叠了三个空态

Unpublished.vue
现状
表格自带「暂无数据」→ 下方又一张 el-empty 插画「暂无待发布点评」→ 右下角还有 「共 0 条」分页。三处说同一件事，且位置分散，用户会以为页面加载失败。
建议
✦
当前没有待发布的点评

「通过」与「发布」是两个维度：已通过的点评会先进入这里，确认后再推送给学生。审核队列还有 8 条等待处理。

一个空态 + 一个主行动 · 不渲染表格与分页
  • 用 <template #empty> 接管表格空态，全局只留一处。
  • v-if="total > 0" 控制分页，0 条时不渲染。
  • 空态必须给出路：这里指向「审核队列（8）」，把死路变成下一步。
  • 顺手统一 GateEmpty 与普通空态的视觉：同一套图标容器 + 标题 + 说明，区别只在文案。
影响：空态是演示时最容易点到的页面（新环境种子数据就是空的），现在看起来像 bug。

P1 · 一致性问题

不影响功能，但会让系统看起来「不是一个团队做的」。逐条都有明确落点。

问题位置改法级别
标题重复两遍 AppLayout + 各页 顶栏显示「统计报表」，页面内又是 20px「统计报表」+ 副标题。顶栏改为面包屑 工作台 / 统计报表，或只保留产品名 + 全局操作，页面标题独占一层。 P1
